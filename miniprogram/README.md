# RiskPilot 微信小程序原型

这是独立于 V1 网页的原生微信小程序工程，两个产品入口都只调用 `/api/v2`：

- 风险报告：生成、查询、校验、历史列表、复制 Markdown、进入同股票挑战；
- 时间穿越挑战：创建/恢复实验、预览仓位、连续提交、服务端复算成绩和排行榜。

## 本地打开

1. 启动 V2 API，并通过 `RISKPILOT_API_TOKENS_JSON` 配置本地开发令牌。
2. 打开微信开发者工具，导入本目录 `miniprogram/`。
3. 原型使用 `touristappid`；如果开发者工具要求，请选择测试号或填写自己的 AppID。
4. 在开发者工具的项目设置中，开发阶段临时关闭“校验合法域名”。
5. 打开小程序首页的“本地联调”，填写 API 地址和同一个开发令牌。

默认地址是 `http://127.0.0.1:8001`。开发令牌只存储在当前开发设备的微信本地存储中，
不会写进源码。正式版本不能继续使用 Bearer 开发令牌，必须接入微信登录、备案 HTTPS
域名、服务器域名白名单、限流和隐私合规流程。

## 首版范围

当前原型优先使用证据链已经跑通的 `601318` 历史样本。页面允许输入其他六位代码，
但服务端没有相应证据包时会明确返回不可用，不会合成行情兜底。
